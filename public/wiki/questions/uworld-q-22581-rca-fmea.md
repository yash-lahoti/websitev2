**Prompt:** What is the primary difference between Root Cause Analysis (RCA) and Failure Mode and Effects Analysis (FMEA)?

**Answer:** RCA is a **retrospective** tool used to identify the underlying causes of an error that has *already occurred*. FMEA is a **prospective** tool used to identify potential vulnerabilities and the likelihood of error *before* it occurs.

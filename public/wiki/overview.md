# Step 2 study wiki — overview

This folder is an **LLM-maintained wiki** for USMLE Step 2 prep: illness scripts, factoids, key questions, weak spots, and links to screenshots / question sources.

## Layers

- **`raw/`** — You add sources here only. The agent **reads** but does **not** modify these files without explicit instruction.
- **`wiki/`** — The agent **creates and edits** markdown here.
- **`index.md`** / **`log.md`** (vault root) — Catalog and timeline; agent-updated.

## Maintainer

Use the **step2** skill in nano_claude (**`/step2`** or **`/step2-wiki`**), or read [[AGENTS]] for a short vault-local summary.

## Obsidian

Open **`step2-wiki`** as the vault root. Wikilinks use note names like `[[overview]]`.
